## Как это работает

Каждая выполненная команда молча сохраняется в локальной SQLite-базе, привязанной к **директории**, в которой вы находились. В следующий раз, когда вы начнёте вводить ту же команду в той же директории, она появится как ghost text — подсвеченное предложение, которое принимается нажатием `→`.

```
[ввод]       → стратегия: project_context → память (SQLite) → история
[Enter]      → хук preexec → запись команды (фоново, < 2 мс)
[завершение] → хук precmd  → запись успеха/ошибки (фоново)
[1×/день]    → decay → удаление устаревших записей
```

### Почему привязка к директории?

`make build` в `~/projects/api` — это не то же самое, что `make build` в `~/projects/docs`. Привязка к директориям исключает шум между проектами — тот же принцип, что у [zoxide](https://github.com/ajeetdsouza/zoxide).

### Меню в стиле Fig

Нажмите `Ctrl+F` в любой момент, чтобы открыть интерактивный выбор с оценками:

| Источник | Цвет | Описание |
|----------|------|----------|
| memory | зелёный | Ваши прошлые команды здесь, отсортированные по оценке |
| project | жёлтый | Цели Makefile, скрипты npm, подкоманды cargo |
| dir | пурпурный | Реальные пути для команд `cd` |
| path | голубой | Исполняемые файлы в `$PATH` |
| history | серый | История shell |

### Умный `cd`

Ввод `cd dev/myproject` когда реальный путь `~/Dev/MyProject` (другой регистр) — плагин найдёт его через:
1. Проверку точного пути
2. Нечувствительный к регистру glob в той же родительской директории
3. Поиск в `~/Dev`, `~/Projects`, `~/src`, `~`

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `→` или `End` | Принять предложение ghost text |
| `Ctrl+F` | Открыть интерактивное меню в стиле Fig |
| `Ctrl+\` | **Пауза / продолжение** ghost text |
| `Ctrl+E` | Отклонить текущее предложение |

## Формула оценки

```
score = 0.35 × log(1 + частота)
      + 0.25 × exp(−возраст_часов × ln2 / полупериод_часов)
      + 0.30 × совпадение_префикса     # 1.0 точное, 0.8 начало, 0.3 слово
      + 0.05 × является_проектом       # цель Makefile/package.json
      + 0.05 × доля_успехов            # доля запусков с кодом выхода 0
```

**Почему `log(1 + freq)`?** Сжимает шкалу — разница между 1 и 2 запусками важнее, чем между 100 и 101.

**Почему экспоненциальный распад?** Моделирует [кривую забывания Эббингауза](https://ru.wikipedia.org/wiki/Кривая_забывания). Период полураспада по умолчанию: **7 дней**.

## Конфигурация

Переменные устанавливаются в `~/.zshrc` **до** `source $ZSH/oh-my-zsh.sh`:

```zsh
ZSH_AUTOSUGGEST_STRATEGY=(smart_context history)
SMART_SUGGEST_MENU_KEY="^F"          # Ctrl+F для меню
SMART_SUGGEST_TOGGLE_KEY="^\\"       # Ctrl+\ для паузы
SMART_SUGGEST_HALF_LIFE_HOURS=168    # 7 дней
SMART_SUGGEST_STALE_DAYS=90          # 90 дней до удаления
```
